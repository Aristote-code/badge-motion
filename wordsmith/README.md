# Wordsmith badge (fountain pen writing a flourish)

`wordsmith-badge.svg` is the artwork (generated by `gen.py`). `wordsmith-badge.html` animates whatever is in it (same workflow as the other badges).

## Edit → see it animate

1. `node studio.mjs` and open http://localhost:5186.
2. Edit `wordsmith-badge.svg` and save over it; the animation reloads. Click the badge to replay with sound.
3. From Figma, tick **Include "id" attribute** when exporting SVG, or just say "I updated it in Figma" and it can be pulled from the frame.

## Export

- `node render.mjs` → intro video (8.5 s) + seamless idle loop (4 s), both with sound, plus PNG, WAV, `.ahap`, Android Kotlin, haptics JSON
- `node render.mjs --extras` → only the sound + haptics files

## The choreography

| Time | What happens | Sound | Haptic |
|---|---|---|---|
| 0.0 | medal pops in | marimba boop | tap |
| 0.16 | ribbons drop and swing | soft double flap | light tap |
| 0.34 → 0.82 | the sheet slides in and unrolls from its left edge | soft paper whoosh + quick pluck run | light rumble |
| 0.7 → 1.02 | the bottom-right corner curls up | woody "tok" | light tap |
| 0.86 → 1.26 | the pen swoops in from the top-right and lands its nib on the start of the flourish | falling glide + landing marimba | tap on landing |
| 1.32 → 2.52 | the pen writes: the calligraphic ink stroke draws on and the nib tip rides its end the whole way | rising glissando of quick soft plucks ("scribble") | light continuous buzz |
| 2.52 → 2.72 | the pen lifts and taps a full stop; the ink dot plops in with a splash ring | "plip" | tap |
| 2.72 → 2.98 | the pen glides back and rests at the end of the line | soft marimba settle | — |
| 3.06 / 3.14 | gold star pops with a spin, the two red burst dashes shoot out | bell | crisp tap |
| 3.12 → 3.72 | a light glint runs along the ink | — | — |
| 3.46 | complete: rings, confetti, light rays | "ta-da!" chord | strong hit + ticks |
| 3.54 | sparkle stars burst in | tings | — |
| 3.68 | shine sweep | harp glissando | — |
| idle | the pen hovers just above the paper and sways, the ink glint runs along the stroke, the star twinkles, the burst dashes pulse, the ink dot wobbles, the curl flicks, rays turn | faint glimmer tings with the glint, shine once per loop | — |

Timings live in `T` near the top of the script in `wordsmith-badge.html` (source: `middle.js`); sounds in `sounds.js`; sounds + haptics cues in `buildCues`.

## Layer names

| Layer | What it does |
|---|---|
| `badge`, `medal`, `ribbon-left`, `ribbon-right`, `sparkles` (`star-2`, `star-3`) | as in the other badges |
| `paper` | the sheet; unrolls from the left edge of `paper-sheet` |
| `paper-sheet` | the sheet face (sets the unroll edge) |
| `paper-curl` | the curled corner; rolls up from its bottom-right corner |
| `ink` | holds the ink stroke |
| `ink-body` | the calligraphic stroke shape (filled); revealed along `ink-path` |
| `ink-path` | the stroke's centreline (keep it a stroke, and keep it ending at the nib tip): sets the write-on path, where the pen tip goes, and the glint path |
| `ink-dot` | the full stop; plops in when the pen taps it |
| `pen-clip` | static clip to the medal face (the barrel runs under the rim); do not animate |
| `pen` | the fountain pen; swoops in, writes along `ink-path`, taps the dot, hovers |
| `nib` | used to work out the pen's axis (tip → back), so the lift/hover moves along the pen |
| `star` | the gold star; pops |
| `burst` | each child is a red dash; shoots out from the star |
