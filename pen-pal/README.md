# Pen Pal badge (open envelope + letter)

`pen-pal-badge.svg` is the artwork (generated by `gen.py`; `python3 gen.py --closed` writes it with the closed flap visible). `pen-pal-badge.html` animates whatever is in it (same workflow as the other badges).

## Edit → see it animate

1. `node studio.mjs` and open http://localhost:5191.
2. Edit `pen-pal-badge.svg` and save over it; the animation reloads. Click the badge to replay with sound.
3. From Figma, tick **Include "id" attribute** when exporting SVG, or just say "I updated it in Figma" and it can be pulled from the frame.

## Export

- `node render.mjs` → intro video (8.8 s) + seamless idle loop (4 s), both with sound, plus PNG, WAV, `.ahap`, Android Kotlin, haptics JSON
- `node render.mjs --extras` → only the sound + haptics files

## The choreography

| Time | What happens | Sound | Haptic |
|---|---|---|---|
| 0.0 | medal pops in | marimba boop | tap |
| 0.16 | ribbons drop and swing | soft double flap | light tap |
| 0.34 → 0.86 | closed envelope (flap down, heart seal) flies in from the top right, spinning upright and growing | soft airy swoosh | — |
| 0.86 | envelope lands with a paper squash | papery tap + low woody knock | tap |
| 1.0 | heart seal swells and pops off | rising "blup" | light tick |
| 1.18 → 1.34 | gold outer side of the flap folds up about the top edge to nothing | quick rising "fwip" pluck | — |
| 1.34 → 1.6 | purple inner side of the flap unfolds upward behind the letter (small hop of the envelope) | woody landing note | tap |
| 1.6 → 2.1 | letter slides up out of the pocket (clipped to the envelope, slight stretch); envelope settles down to centre the composition | smooth rising glide | light buzz + landing tap |
| 2.12 / 2.3 / 2.48 | the three text lines write on left → right | soft pen ticks + climbing plucks | light ticks |
| 2.7 | heart pops onto the letter | warm boing + bell | tap |
| 2.96 / 3.34 | heart beats twice | low marimba "ba-dum" | double tap each beat |
| 3.48 / 3.55 / 3.62 | burst dashes pop one by one | three bright plucks | light ticks |
| 3.78 | complete: rings, confetti, light rays | "ta-da!" chord | strong hit + ticks |
| 3.86 | sparkle stars burst in | tings | — |
| 4.0 | shine sweep | harp glissando | — |
| idle | heart beats twice per loop (0.5 s, 2.5 s), letter bobs gently, burst dashes pulse, flap flutters slightly, stars twinkle, rays turn | soft ba-dum on each idle beat, shine once per loop | — |

Timings live in `T` near the top of the script in `pen-pal-badge.html` (source: `middle.js`); sounds in `sounds.js`; cues and haptics in `buildCues`.

## Layer names

| Layer | What it does |
|---|---|
| `badge`, `medal`, `ribbon-left`, `ribbon-right`, `sparkles` | as in the other badges |
| `envelope` | the whole envelope; flies in, lands, settles |
| `envelope-back` | the back panel / purple lining; its top edge is the flap hinge |
| `flap-open` | the flap's inner (purple) side, folded up behind the letter; grows up from the hinge |
| `flap-closed` | the flap's outer (gold) side, folded down over the pocket; folds up to 0 about the hinge (hidden in the static file) |
| `seal` | heart seal on the closed flap; pops off |
| `letter` | the letter card; slides up out of the pocket (its unnamed parent group clips it to the envelope) |
| `letter-lines` | each child (`line-1..3`) is a stroked line; writes on left → right in order |
| `heart` | heart on the letter; pops and beats |
| `pocket` | side flaps + bottom flap, in front of the letter |
| `burst` | each child (`burst-1..3`) is a dash; pops in order, then pulses |
