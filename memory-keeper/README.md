# Memory Keeper badge (baby elephant peeking over a purple hexagon)

Elephants never forget. `memory-keeper-badge.svg` is the artwork, generated by `gen.py`. `memory-keeper-badge.html` animates it, using the same workflow as the other badges.

The first version (a logo-style elephant head) is kept in `reference/v1-logo/`.

## Artwork (matches the real image)

The artwork follows the user's illustration, `reference/memory-keeper-reference.svg` (the vectorised version of their real image). Every shape of it is redrawn as a smooth curve fitted to its outline (`reference/fitted-shapes.json`), so the badge keeps all of the illustration's shading:
- violet inner rims and magenta bands in the ears, gloss spots
- layered blues on the trunk
- lavender lids and highlights in the eyes
- paw domes with pink-shaded toenails

The shapes are then sorted into parts that can move on their own (`reference/groups.json`).

To make it animate cleanly:
- **Inner face.** It is repainted, so no dark elephant-shaped "ghost" shows before the elephant arrives.
- **Outlines.** Each moving part carries its own dark outline.
- **Ear masks.** The head base is masked under the ears, so they can flap.
- **Bursts.** The burst wedges are redrawn cleanly.

Earlier attempts are kept in `reference/`:
- `gen-traced-elephant.py`: raw trace
- `elephant.py`: hand-drawn version, judged too simple next to the real image
- `v1-logo/`: the first logo-style elephant

## Edit → see it animate

1. Run `node studio.mjs` and open http://localhost:5194.
2. Edit `memory-keeper-badge.svg` and save over it. The animation reloads.

## Export

`node render.mjs` writes:
- the intro video (4.0 s) and a seamless 4 s idle loop, both with sound
- PNG and WAV
- `.ahap`, Android Kotlin and haptics JSON

## The choreography

| Time | What happens | Sound | Haptic |
|---|---|---|---|
| 0.0 | hexagon pops in | marimba boop | tap |
| 0.32 → 0.82 | the elephant peeks up from behind the bottom edge (clipped inside the hexagon) and lands with a squash | low rising glide | — |
| 0.46 / 0.56 | paws slap onto the rim, one after the other, right behind the rising body | two woody pats | taps |
| 0.92 → 1.42 | ears flap open from folded-in, overshoot and flap | airy flap + woody notes | soft buzz + tap |
| 1.42 / 1.68 | happy double blink, brows lift | tiny "tink" | taps |
| 1.6 → 2.2 | the raised trunk waves hello (two swings), the elephant leans in | rising pluck run | — |
| 2.2 | "toot-toot!": the trunk puffs | friendly two-note trumpet | buzz + tap |
| 2.22 / 2.42 / 2.62 | three gold notes drift out of the trunk tip, up over the head | G5 / B5 / D6 plinks | ticks |
| 2.36 → 2.6 | the four burst wedges pop out | bright pings | — |
| 2.95 | complete: rings, confetti, light rays | "ta-da!" chord | strong hit + ticks |
| 3.18 | shine sweep | harp glissando | — |
| idle (4 s) | ears fan, trunk sways, head breathes, paws tap (0.4 s), one blink (1.3 s), bursts pulse (2.0 s), shine (2.6 s) | blink tink, shine | — |

Timings live in `T` near the top of `middle.js`, and sounds in `sounds.js`. Rebuild from `badges/` with:

```bash
python3 _kit/assemble.py memory-keeper memory-keeper/middle.js memory-keeper/sounds.js --title "Memory Keeper" --intro 3.98 --layers badge,medal,medal-outline,burst,elephant,rise,ear-left,ear-right,head,trunk,mouth,eyes,eye-left,eye-right,brows,paw-left,paw-right,sparkles --port 5194
```

## Layer names

| Layer | What it does |
|---|---|
| `badge`, `medal` (`medal-outline`, `medal-face`) | hexagon frame; pops in, squashes at the finale |
| `elephant` > `rise` | everything but the paws; rises up from behind the bottom edge inside `clip-peek`, breathes |
| `ear-left`, `ear-right` | flap open about where they meet the head, then fan in the loop |
| `head`, `mouth` | face detail (static) |
| `trunk` | the raised part of the trunk; waves, puffs on the toot, sways |
| `eye-left`, `eye-right` | blink |
| `brows` | lift |
| `paw-left`, `paw-right` | slap onto the rim; tap in the loop. Not clipped, so they sit over the rim. The chest travels with the left paw |
| `burst` (`burst-1..4`) | pop out from their inner ends, pulse in the loop |
| `sparkles` | empty |
