# Bookworm badge (open book + star)

`bookworm-badge.svg` is the artwork (generated by `gen.py`). `bookworm-badge.html` animates whatever is in it (same workflow as the other badges).

## Edit → see it animate

1. `node studio.mjs` and open http://localhost:5185.
2. Edit `bookworm-badge.svg` and save over it; the animation reloads. Click the badge to replay with sound.
3. From Figma, tick **Include "id" attribute** when exporting SVG, or just say "I updated it in Figma" and it can be pulled from the frame.

## Export

- `node render.mjs` → intro video (8.4 s) + seamless idle loop (4 s), both with sound, plus PNG, WAV, `.ahap`, Android Kotlin, haptics JSON
- `node render.mjs --extras` → only the sound + haptics files

## Artwork (follows the reference SVG)

Drawn to match `reference/bookworm-reference.svg` (overlaid at 0.72 scale, centre (624, 546) → (420, 412)):
- The open book is seen from a little below, so the rounded back of the spine is the gold cylinder standing in front of the gutter (two dark bands), with the pages fanning out of its open top.
- Covers are boards tipped back in a shallow V, each with an embossed inset panel and a light top rim.
- Per side: three long pages sweeping up and out with up-curling tips (back page highest) plus a narrow curled page at the gutter.
- Wide gold ribbon bookmark over the front of the right cover, forked tail.
- One big full star with two red capsule dashes angled out from the book (the `sparkles` layer is kept, empty).

## The choreography

| Time | What happens | Sound | Haptic |
|---|---|---|---|
| 0.0 | medal pops in | marimba boop | tap |
| 0.16 | ribbons drop and swing | soft double flap | light tap |
| 0.34 → 0.72 | a closed book (front cover facing us, spine on the left, page block + bookmark tail showing) drops in from inside the medal face and lands with a squash + little bounce | soft woody thump + knock | tap (+ light echo) |
| 0.9 → 1.08 | the front cover swings open: scaleX → 0 about the spine while the book slides so the spine sits on the centre, revealing the page block | two woody notes spreading L/R, soft rising breath | soft buzz + tap |
| 1.08 → 1.42 | switch to the open book: the front cover carries on over to the left (cover-left scaleX 0 → 1), the back cover settles flat | (same) | — |
| 1.04 → 1.6 | page layers fan up out of the gutter, back to front, both sides | airy pluck shimmer | — |
| 1.52 / 1.66 / 1.80 / 1.94 | four leaves flip from the right page to the left, one after another | paper "fff" + soft pluck, rising C E G C | light ticks |
| 2.38 → 2.86 | bookmark ribbon unfurls down and swings | downward slide landing on a tok | light tap |
| 2.74 → 3.18 | star rises out of the book, spinning into place; burst dashes shoot out at 3.1 | rising glide, then a gentle bell "ding" | crisp tap |
| 3.4 | complete: rings, confetti, light rays | "ta-da!" chord | strong hit + ticks |
| 3.48 | sparkle stars burst in | tings | — |
| 3.62 | shine sweep | harp glissando | — |
| idle (4 s) | the top page turns over right → left (0.5–1.6 s), star twinkles and sways, dashes pulse, book breathes, bookmark sways | soft page pluck, shine once per loop | — |

Timings live in `T` near the top of the script in `bookworm-badge.html` (source: `middle.js`); sounds in `sounds.js`; cues/haptics in `buildCues`. Rebuild with
`python3 ../_kit/assemble.py bookworm bookworm/middle.js bookworm/sounds.js --title "Bookworm" --intro 4.42 --layers badge,medal,ribbon-left,ribbon-right,book,book-closed,closed-front,spine,cover-left,cover-right,pages-left,pages-right,leaves,bookmark,star,burst,sparkles --port 5185` (run from `badges/`).

## Layer names

| Layer | What it does |
|---|---|
| `badge`, `medal`, `ribbon-left`, `ribbon-right`, `sparkles` (`star-1`, `star-2`) | as in the other badges |
| `book` | the whole book; drops in, squashes on landing, breathes |
| `book-closed` | the shut book shown at the start of the intro; hidden (`opacity="0"`) in the static SVG, so the file shows the open book. Children: `closed-back` (back cover, page block, bookmark tail), `closed-front` (front cover; swings open through 0 about the spine), `closed-spine`. Preview it with `python3 gen.py --closed <out.svg>` |
| `spine` | gold spine cylinder in front of the gutter (shown once the book is open) |
| `cover-left`, `cover-right` | the open covers: left grows out from the gutter (the front cover landing), right settles flat |
| `pages-left`, `pages-right` | each child (`page-left-1..4`, `page-right-1..4`, back → front; 4 = the curled gutter page) fans up out of the gutter in order |
| `leaves` | each child (`leaf-1..4`) is a loose leaf identical to the front page, drawn resting on the left stack; flips over from the right. The last one turns again every idle loop |
| `bookmark` | unfurls down from its top edge |
| `star` | rises out of the gutter and spins into place, twinkles |
| `burst` | each child (`burst-left`, `burst-right`) shoots out from the star centre |
