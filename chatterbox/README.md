# Chatterbox badge (laughing speech bubble + typing bubble)

`chatterbox-badge.svg` is the artwork (generated by `gen.py`). `chatterbox-badge.html` animates whatever is in it (same workflow as the other badges).

## Edit → see it animate

1. `node studio.mjs` and open http://localhost:5189.
2. Edit `chatterbox-badge.svg` and save over it; the animation reloads. Click the badge to replay with sound.
3. From Figma, tick **Include "id" attribute** when exporting SVG, or just say "I updated it in Figma" and it can be pulled from the frame.

## Export

- `node render.mjs` → intro video (8.5 s) + seamless idle loop (4 s), both with sound, plus PNG, WAV, `.ahap`, Android Kotlin, haptics JSON
- `node render.mjs --extras` → only the sound + haptics files

## The choreography

| Time | What happens | Sound | Haptic |
|---|---|---|---|
| 0.0 | medal pops in | marimba boop | tap |
| 0.16 | ribbons drop and swing | soft double flap | light tap |
| 0.42 | yellow bubble pops out of its tail tip (eyes open, little smile) | bubbly "boop" (E) | tap |
| 0.92 | purple bubble pops out of its tail tip; the yellow face glances at it | higher "boop" (B) | tap |
| 1.30 / 1.41 / 1.52 | typing dots bounce in a wave, each lighting up as it hops | soft plinks E, G, A | very light ticks |
| 1.76 / 1.87 / 1.98 | second typing wave | soft plinks | very light ticks |
| 2.26 | yellow reacts: eyes squeeze into happy arcs, the smile becomes the open laugh | — | — |
| 2.42 → 3.16 | "ha-ha": two crouch / hop-stretched / land-squash bounces, the mouth opens wider on each | two rising marimba + bell pairs (G→B, C→E) at 2.48 / 2.86 | playful double tap |
| 3.04 → 3.24 | burst dashes pop outward one by one | sparkly pluck run | light tap |
| 3.46 | complete: rings, confetti, light rays | "ta-da!" chord | strong hit + ticks |
| 3.54 | sparkle stars burst in | tings | — |
| 3.68 | shine sweep | harp glissando | — |
| idle (4 s) | bubbles float in counter-phase; typing-dot wave at 0.3 s; small "ha-ha" double hop at 1.5 s with a burst-dash pulse; stars twinkle, rays turn; shine at 2.6 s | quiet plinks, quiet "ha-ha", shine | — |

Timings live in `T`, `HA` and `IDLE` near the top of the script in `chatterbox-badge.html` (source: `middle.js`); sounds in `sounds.js`; cues/haptics in `buildCues`.

## Layer names

| Layer | What it does |
|---|---|
| `badge`, `medal`, `ribbon-left`, `ribbon-right`, `sparkles` (`star-1`, `star-2`) | as in the other badges |
| `bubble-yellow` | pops from its tail tip (the point of its first path farthest from its centre), hops/squashes for the laugh, floats |
| `face` | glances toward the purple bubble while it types |
| `eyes-open` / `eyes-happy` | swap when it laughs (open eyes squeeze shut, happy arcs spring up). `eyes-open` is hidden in the static artwork |
| `mouth-smile` / `mouth-laugh` | swap; the laugh opens from its top edge and pulses on each "ha". `mouth-smile` is hidden in the static artwork |
| `bubble-purple` | pops from its tail tip, breathes with the dots, floats |
| `typing-dots` | each child (`dot-1..3`) bounces in a wave, in order |
| `burst` | each child (`dash-1..5`) pops outward from the yellow bubble, in order |
